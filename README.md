# HealthCare AI - AI-Powered Medical Diagnosis System

## Overview

HealthCare AI is an advanced web-based application designed to assist in medical diagnosis using Artificial Intelligence. The system uses machine learning models to analyze various health parameters and provide preliminary predictions for multiple diseases. This project is a team effort aimed at creating a robust, accessible, and user-friendly Health Detection System.

## Features

The system supports prediction and diagnosis assistance for the following diseases:
- Alzheimer's Disease
- Brain Tumor
- Breast Cancer
- Covid-19
- Diabetes
- Hepatitis
- Kidney Disease
- Pneumonia

## Technology Stack

- **Backend:** Python, Flask
- **Frontend:** HTML, CSS, JavaScript
- **Machine Learning:** Scikit-Learn, TensorFlow/Keras (depending on the model)

## Setup Instructions

1. **Clone the repository:**
   ```bash
   git clone https://github.com/akmaurya321/HealthDetectionSystem.git
   cd HealthDetectionSystem
   ```

2. **Create a Virtual Environment:**
   ```bash
   python -m venv venv
   # On Windows:
   venv\Scripts\activate
   # On macOS/Linux:
   source venv/bin/activate
   ```

3. **Install Dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Run the Application:**
   Navigate into the website directory and run the main application:
   ```bash
   cd HealthCareAI-Website
   python main.py
   ```

5. **Access the Website:**
   Open your browser and navigate to `http://127.0.0.1:5000` (or the port specified in the console).
